# Workspace research action center

Open **Research library → Action center** for one queue of follow-up tasks across workspace collections. English, Spanish and French controls are available. This view uses the original collection tasks; it does not create a second plan or saved research snapshot.

## Workflow

Filter by collection, everyone/current user/unassigned/specific member, task status, due window and task title. Filters intersect. The initial view shows unfinished work for everyone across all collections. Reset restores that view. Counts describe the matching rows, and rendering is limited to 50 rows per page after filtering and priority sorting.

Unfinished tasks sort first, earliest due date first, with undated tasks last; creation time and task ID settle ties. Overdue means an unfinished task due before the browser's local calendar day. Due today is not overdue. The next seven days includes today and the following six calendar days, across month/year and daylight-saving changes. Completed tasks do not appear in overdue/today/seven-day windows. No-date filtering may include completed tasks if the status filter permits them. The local day updates each minute, when the window gains focus, and on refresh.

Edit a task's title, assignee, due date and progress directly in the queue. Changes use the original collection-task endpoint and version. Completing or reopening a task follows existing completion timestamp rules and never approves findings, checks sources, or changes exports. Concurrent divergent changes return a conflict; errors clear the queue/editor until refreshed. No email/reminders, new domain, provider calls or automatic task creation are involved.

Open linked research directly in the existing authenticated source viewer, single-answer review dialog or brief view. Open a collection dashboard without leaving the action center. Closing answer review or the collection dashboard refreshes the queue. Publishing a source correction or deleting a source in the parent source viewer also refreshes the action center. Other sessions' changes become visible through explicit refresh and are protected by existing task version checks.

## Current sources, access and bounds

`GET /api/library/action-center` returns current task views, collection IDs/titles, member IDs/names, current user ID and edit capability. Target metadata contains a display label capped at 160 characters and the answer scope needed for direct review. It returns no member emails, workspace IDs, request IDs/hashes, transcript text, finding bodies, quotations, source fingerprints or review history. Other methods return 405 and unsupported nested routes return 404. Normal workspace authentication applies; public requests return 401. Workspace readers can view the queue; only existing editors can modify original tasks.

Before returning rows, the server prunes collection memberships/tasks, revalidates distinct linked answers and linked briefs (including global answers behind linked briefs), then prunes again inside one transaction. Missing/withdrawn sources and lost collection dependencies therefore cannot leave task text in the current queue. Existing task rules continue to remove linked tasks and clear removed/moved assignees. Dependency existence is resolved in batches during pruning. No queue records or label copies are persisted.

The existing limits bound the queue to 50 collections × 100 tasks. Selecting a collection or assignee that disappears retains the filter with an explicit unavailable label; refresh never silently expands the selection to everyone/all collections. Deleted sources/tasks retain only existing content-free request tombstones, never action-center snapshots.
