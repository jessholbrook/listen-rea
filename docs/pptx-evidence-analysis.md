# AI analysis of verified PPTX excerpts

This milestone combines synthesis, source-linked Q&A and saved/reviewed report answers. It builds on [private PPTX uploads and verified slide evidence](participant-pptx.md). Include verified passages, create a current evidence memo, then use the PPTX controls in Analysis. Uploading alone never invokes AI. Ordinary interview/theme analysis continues to use written answers.

## Explicit, limited AI requests

Synthesis and questions send OpenAI only the selected excerpt text, exact PPTX ID, verification version, original slide number and UTF-16 start/end offsets, plus reporting language and the question for Q&A. Full slides/decks, original files, unselected text, interview answers, reviewer names, private corrections/history and source fingerprints are not included. Preparation omits speaker notes, images, hidden content and layout; AI cannot inspect these. Prompts treat embedded instructions as untrusted data and prohibit invented sources, participant attribution, counts/prevalence, identity inference and independent verification claims.

Both calls use `store:false`, a 50-second deadline and bounded output (3,000 synthesis tokens / 2,000 Q&A tokens). Synthesis has at most six findings with 1–10 exact supplied-passage citations per finding. Q&A has at most 20 citations; uncited answers become fixed English, Spanish or French insufficiency text. Each citation must exactly match an included passage, including slide number, source ID, verification version, offsets and complete quote. Unsupported or unavailable generation saves no draft. Limits are 100 source records / 150,000 serialized code units per request; workspace rate limits are six synthesis and ten Q&A actions per window.

## Synthesis and temporary questions

Synthesis saves a server-attributed draft. Review/edit the interpretations and limitations, then separately review the memo before sharing or creating a report. Edits reset the attestation. Regeneration, edits or discard revoke derived editions/snapshots/share links. Only reviewed synthesis enters memo exports, report editions and editable PowerPoint appendices, with exact slide references, model/prompt provenance and reviewer attribution.

Ordinary questions are temporary and do not save an answer or change memo/report state. Exact citation controls revalidate the current source and highlight the selected range in prepared slide text; response links open the authorized source. Clear/reload removes temporary answers. Context changes and unmounts ignore late replies.

## Saved answers and report inclusion

“Ask and save” explicitly creates a private draft, preserving an immutable generated original, server provenance, frozen cited sources and attributed revision history. The latest answer starts unreviewed with report inclusion off. Up to 20 answers and 50 revisions per answer are allowed, with a 250,000 serialized-code-unit analysis storage limit.

Review the answer against the prepared text and selected passages. Citation edits must match both the current analysis and the frozen cited sources. Report inclusion requires explicit review and at least one exact citation; an uncited insufficiency answer may remain private. Private edits preserve existing reports. Included edits, withdrawal or deletion revoke derived reports/shares and reset memo review. Report projections contain only the current reviewed answer/question, cited source subset, reviewer attribution and generation provenance, never the original or private history. Sample/theme counts remain unchanged.

## Source lifecycle and access

Every action requires edit authority, the exact workspace/study/scope, a current complete eligible response, unchanged source/digest/verification, analysis ID/version and reporting language. AI requests recheck after generation before writing. Shares, report creation/read/edit/restore/export and deck generation revalidate sources and included answer projections. Withdrawal or source/response erasure removes dependent analyses (including originals/history), reports/snapshots and shares; late writes fail. External API/MCP and participant projections omit these private analysis records. Authorized researchers retain source access; public report viewers receive selected text only.
